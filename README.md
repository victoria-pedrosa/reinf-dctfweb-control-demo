# Demonstração — Controle de entregas de REINF, MIT e DCTFWeb

> Projeto de portfólio de **Victória Pedrosa**. **Demonstração** de controle de entregas de REINF, MIT e DCTFWeb — versão com dados fictícios (nomes, CNPJs, e-mails e IDs internos substituídos).

## Problema de negócio
Controlar a entrega de REINF, MIT e DCTFWeb por empresa e competência era disperso.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Controle em planilhas. | Aplicação web de controle das entregas por empresa, com importação e verificação de recibos. |

## Ganho
- Visão única das entregas por competência.

## Tecnologias
HTML/JavaScript, SQLite

## Arquivos
- `reinf-dctfweb-control_1.html`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
